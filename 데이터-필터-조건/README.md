## 핵심 저장 원칙 (공통 불변 규칙)

1. **조건 일치 공고만 `신규(new)`로 저장:** 모든 관문(날짜 → 직무 키워드 → 근무지역 → 경력)을 순서대로 통과한 공고만 **무조건 `status = 'new'` (신규)**로 DB에 저장합니다.
2. **조건 불일치 공고는 DB 미저장:** 어느 한 단계라도 통과하지 못한 공고는 **DB에 저장하지 않고 즉시 스킵(`continue`)**합니다.
3. **`확인완료(rejected)` 자동 유입 금지:** `확인완료` 상태는 오직 사용자가 대시보드에서 직접 **`[확인완료]` 버튼을 클릭한 경우에만** 설정됩니다.
